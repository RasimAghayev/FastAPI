# FastAPI Todo API

A FastAPI application implementing a Todo CRUD API with Tortoise ORM and SQLite.

## Overview

- **Language**: Python
- **Framework**: FastAPI
- **ORM**: Tortoise ORM (async)
- **Database**: SQLite (`store.db`)
- **API Docs**: Auto-generated by FastAPI at `/redocs` and `/redoc`

## Features

- Create, read, update, and delete Todo items
- Async database operations via Tortoise ORM
- Automatic OpenAPI/Swagger documentation
- SQLite backend with auto-schema generation

## Endpoints

| Method | Route | Description |
|--------|-------|-------------|
| GET | `/` | Health check — returns `{"hello": "world"}` |
| POST | `/todo` | Create a new Todo item |
| GET | `/todo/{id}` | Get a single Todo by ID |
| PUT | `/todo/{id}` | Update a Todo by ID |
| DELETE | `/todo/{id}` | Delete a Todo by ID |

## Todo Model

| Field | Type | Description |
|-------|------|-------------|
| `id` | Int (PK) | Auto-generated primary key |
| `todo` | CharField(250) | Todo description |
| `due_date` | CharField(250) | Due date string |

## Setup

### Prerequisites

- Python 3.8+

### Installation

```bash
# Create and activate virtual environment
python -m venv env
source env/bin/activate  # Linux/Mac
# or
.\env\Scripts\activate    # Windows

# Install dependencies
pip install --upgrade pip
pip install fastapi uvicorn tortoise-orm python-multipart

# Run the application
uvicorn main:app --reload
```

### Gitpod (one-click dev environment)

[Open in Gitpod](https://gitpod.io/#https://github.com/RasimAghayev/FastAPI) — the `.gitpod.yml` automates environment setup and starts the server.

## Running

After setup, the API is available at `http://localhost:8000`.

- API docs (Swagger UI): `http://localhost:8000/redocs`
- API docs (ReDoc): `http://localhost:8000/redoc`
- Health check: `http://localhost:8000/`
