- Current vs latest registry versions: **unconfirmed** in this environment (not queried here); must be resolved in Phase 6 per `DEPENDENCY_MAP.md`/registry.
- Vulnerability scan: **not run** in this phase (no CI/tooling baseline); treat as unknown.

## 3. Security review (working tree, redacted)
- **Secret scan (pattern-based, repo files excluding `env/`, `.git`, `__pycache__`, `store.db*`):** no matches for common AWS/GitHub/OpenAI-style tokens, private key blocks, or obvious password/api_key/secret/token assignments. Result: `SCAN_DONE`, no findings.
- **Committed artifacts:** `store.db`, `store.db-shm`, `store.db-wal` are present (data files, not secrets) — hygiene/integrity risk.
- **App security:** no authn/authz, no rate limiting, no explicit CORS, hardcoded DB path; acceptable only for isolated local/demo use.
- **.gitignore:** missing — increases risk of committing secrets/env/db/venv artifacts in future.
- **Dependency/config secret smells:** none observed in source; `main.py` contains no credential values (DB URL is local file path).

## 4. Correctness and quality observations
- `due_date` modeled/accepted as string; no semantic date validation.
- No list endpoint/pagination; limited API completeness for typical Todo apps (may be intentional).
- Schema generator name typo: `TodoIn_Pydantic` created with `name="TooIn"` (`models.py`).
- Startup performs schema generation (`generate_schemas=True`) on import/registration — operational side effect.
- README mentions `/redocs` and `/redoc` in text; FastAPI standard docs paths differ in naming — **unverified** (potential doc drift).
